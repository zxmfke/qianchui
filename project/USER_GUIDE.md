## 系统简介

千锤·营销话术AI操作系统是一个 AI Native 的营销话术管理平台，帮助消费医疗、教育培训等行业的销售/客服团队：

- **沉淀话术资产** — 三层话术体系（心理层→策略层→话术层），告别碎片化
- **AI 实时推荐** — 对话中根据客户意图实时推荐最佳话术
- **智能培训** — AI 出题 + 每日一练，新人快速上手
- **模拟演练** — AI 扮演客户，实战场景练习
- **对话诊断** — 粘贴真实对话，AI 从多维度评分和改进建议
- **数据飞轮** — 使用数据反哺话术优化，越用越好

## 快速开始

### 第 1 步：登录系统

打开浏览器访问系统地址，输入管理员分配的账号密码登录。

| 账号类型 | 登录后去哪 | 能做什么 |
|---------|-----------|---------|
| 超级管理员 | 管理后台（数据总览） | 管理所有企业、账号、查看全局数据 |
| 企业管理员 | AI 对话中心 | 管理本企业话术、团队、配置 |
| 团队经理 | AI 对话中心 | 查看团队数据、使用所有功能 |
| 一线员工 | AI 对话中心 | 使用话术、培训、演练 |

### 第 2 步：完成新手引导

首次登录会看到新手引导卡片，跟着引导点击即可快速了解各功能模块的位置和用途。

### 第 3 步：开始使用

进入「AI 对话中心」，在输入框输入问题或场景描述，AI 会推荐相关话术并提供建议。

## 首次使用准备清单

> 以下是管理员（admin 角色）在团队第一次使用系统前需要准备的数据。

### 必备数据（建议首日完成）

#### 1. 话术库 — 至少 10 条核心话术

进入「话术库」→ 点击「新增话术」，每条话术包含：

| 字段 | 说明 | 示例 |
|------|------|------|
| 标题 | 简明的场景名称 | 价格异议-锚定策略 |
| 分类 | 话术类型 | 异议处理 / 开场白 / 促成 / 竞品应对 / 售后 / 复购 |
| 标签 | 关键词标签 | 价格, 锚定, ROI |
| 心理层 | 客户心理分析 | 客户对价格敏感，需通过锚定效应重塑价值认知 |
| 策略层 | 应对策略 | 先抛出高价锚点，再引导到实际价格形成对比 |
| 话术内容 | 具体话术文本 | 您关注价格说明您很理性... |

**建议按以下分类各准备 2-3 条：**

- 开场白（首次咨询破冰）
- 异议处理（价格/效果/信任质疑）
- 促成技巧（犹豫不决/预算不足）
- 竞品应对（客户对比竞品）
- 售后服务（投诉/不满）
- 复购引导（老客户维护）

#### 2. 企业记忆 — 基础业务数据

进入「企业记忆」，分别在三个 Tab 下添加：

**痛点库（至少 3 个）：**

| 字段 | 示例 |
|------|------|
| 痛点名称 | 获客成本居高不下 |
| 描述 | 传统广告投放 ROI 持续下降，单个获客成本超过 300 元 |
| 关键词 | 获客, 成本, ROI |

**产品库（至少 2 个）：**

| 字段 | 示例 |
|------|------|
| 产品名称 | 智能获客助手 |
| 描述 | AI 驱动的多渠道获客解决方案 |
| 优先级 | P0 |

**服务库（至少 2 个）：**

| 字段 | 示例 |
|------|------|
| 服务名称 | 话术定制服务 |
| 描述 | 根据企业业务定制专属话术库 |

### 推荐数据（建议首周完成）

#### 3. 渠道物料

进入「渠道物料」，添加各渠道的营销素材：

- 抖音短视频标题和数据
- 小红书笔记
- 微信公众号文章
- 百度广告文案

#### 4. 团队成员

进入「系统设置」→「团队管理」，邀请团队成员并分配角色。

#### 5. AI 模型配置

进入「系统设置」→「模型配置」：

- 填写 API Key（支持 OpenAI、Azure、DeepSeek 等）
- 调整 Temperature（建议 0.7）
- 选择模型（建议 gpt-4 或同等能力模型）

## 功能模块详解

### AI 对话中心

系统的核心入口。在输入框描述你的场景或问题，AI 会：
- 推荐匹配的话术
- 提供应对策略建议
- 根据企业记忆（痛点、产品、服务）给出个性化建议

**使用技巧：**
- 描述越具体，推荐越精准："客户说你们比 XX 贵 30%，怎么回应？"
- 可以直接粘贴客户的对话，AI 会分析并推荐

### 数据看板

展示团队整体的话术使用数据：
- 话术总量、今日复用次数
- 话术排行榜（使用最多、转化最高）
- 团队表现对比
- 使用趋势图

### 话术库

管理所有话术资产：
- 新增/编辑/删除话术
- 按分类、标签筛选
- 查看使用次数和转化率
- 一键复制话术文本

### 培训中心

AI 驱动的每日一练：
- 系统根据话术库自动出题
- 选择题形式，答后有详细解析
- 跟踪正确率和薄弱环节
- 建议每天完成 5 道题

### 演练中心

AI 模拟真实客户场景：
- 选择场景（价格异议/竞品对比/售后投诉等）
- 选择难度（简单/中等/困难）
- AI 扮演不同性格的客户
- 结束后给出多维度评分

### 诊断中心

对话质量诊断：
- 粘贴真实客户对话文本
- AI 从开场白、需求挖掘、异议处理、促成技巧四个维度评分
- 给出具体改进建议
- 历史报告可回顾

### 优化中心

话术优化建议：
- 基于使用数据和诊断结果
- 自动识别低效话术
- 推荐优化方向

### 企业记忆

团队的业务知识库：
- **痛点库** — 客户常见痛点和趋势变化
- **产品库** — 产品信息和推荐策略
- **服务库** — 服务项目和使用效果

### 渠道物料

多渠道营销素材管理：
- 按渠道分类（抖音/小红书/微信/百度）
- 记录素材表现数据
- AI 分析素材卖点和关键词

### 数据飞轮

数据驱动的持续优化：
- 使用数据自动触发话术优化
- 高效话术自动推广
- 低效话术标记和改进
- 形成「使用→反馈→优化→使用」闭环

- "一共有多少企业？"
- "昨天新增多少用户？"
- "今天新增了多少话术？"
- "系统总览"

## 常见问题

### Q: AI 功能不工作怎么办？

确认已在「系统设置」→「模型配置」中填写了有效的 API Key。系统需要连接大语言模型（如 GPT-4）才能提供 AI 推荐、诊断、培训等功能。

### Q: 如何给团队成员创建账号？

- **企业管理员**：进入「系统设置」→「团队管理」添加成员
- **超级管理员**：进入「管理后台」→「账号管理」添加任意企业的成员

### Q: 话术数据会丢失吗？

所有数据存储在 PostgreSQL 数据库中，Docker 部署使用了持久化卷（volumes），正常停止/重启不会丢失数据。建议定期备份，详见 [DEPLOY.md](./DEPLOY.md) 中的备份章节。

### Q: 支持哪些 AI 模型？

系统支持所有 OpenAI 兼容接口的模型：
- OpenAI GPT-4 / GPT-4o / GPT-3.5
- Azure OpenAI
- DeepSeek
- 通义千问（需配置兼容 API 地址）
- 其他兼容 OpenAI 格式的模型

### Q: 如何导入已有的话术数据？

目前支持通过「话术库」页面逐条添加。批量导入功能正在开发中。临时方案：可通过 API 接口批量创建，参考 `/docs` 中的 Swagger 文档。
